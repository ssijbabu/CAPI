**Task:** `vks` provider: create the cluster on the vSphere Supervisor; SSP imports it into OCM once.

**Steps**

1. Implement `vks`: create a Cluster API `Cluster` in the team's vSphere Namespace through the Supervisor API.
2. Because OCM's importer only watches Cluster API clusters on the hub, SSP creates the `ManagedCluster` and applies OCM's import manifests once, with the Supervisor-issued kubeconfig.
3. Inject the SPIRE single-use join token at creation.

**Output:** VKS provider.

**Done when:** A VKS cluster joins OCM with no manual step.
