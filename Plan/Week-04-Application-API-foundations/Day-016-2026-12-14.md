## A · Controllers (2 engineers)

**Task:** Write `Application`, `Environment` and `PromotionPath` types.

**Steps**

1. Add `Application` (cluster-scoped): owner team and groups, type, allowed cluster sets.
2. Add `Environment` (cluster-scoped): stack, production flag, cluster selector, gateway, change window placeholder.
3. Add `PromotionPath` (cluster-scoped): source and target environments.
4. Generate the CRDs at build time; write sample YAML for each in `config/samples`.

**Output:** Three API types with samples.

**Done when:** `./mvnw package` produces valid CRDs; samples apply to a kind hub.

## B · Platform (1 engineer)

**Task:** Enable the `ManifestWorkReplicaSet` feature gate; fan out a hand-written MWRS through a `Placement`.

**Steps**

1. Create a `ManagedClusterSet` binding and a `Placement` selecting `team-dv` and `team-te` (provisioned in week 3).
2. Write a hand-made `ManifestWorkReplicaSet` for nginx; watch the `ManifestWork`s appear in the cluster namespaces.
3. Record the commands in `docs/dev/ocm-fanout.md`.

**Output:** Proven fan-out to SSP-provisioned clusters.

**Done when:** nginx runs on `team-dv` and `team-te`; deleting the MWRS removes it.
