## B · Platform (1 engineer)

**Task:** Prove executor limits: a `ManifestWork` running as a namespaced ServiceAccount cannot write elsewhere.

**Steps**

1. Create a ServiceAccount and a Role limited to one namespace on `team-dv`.
2. Apply a `ManifestWork` with `spec.executor` set to that ServiceAccount.
3. Try to create an object in another namespace through the same work; confirm it fails.
4. Document the hub-side permission needed to use an executor.

**Output:** Executor limits proven.

**Done when:** The out-of-namespace object is refused and the work reports the error.
