## A · Controllers (2 engineers)

**Task:** Create the `ssp` repository: Java 25, Quarkus, Java Operator SDK, Maven; lint and unit-test CI.

**Steps**

1. Create the `ssp` repository with a `main` branch protected by review.
2. Create a Maven multi-module Quarkus project (Java 25) with the `quarkus-operator-sdk` extension: modules `api`, `controllers`, `template`, `webhooks`, `observer`, `cli`.
3. Add `./mvnw verify` to CI: Spotless, Error Prone, JUnit 5, and CRD generation by the Fabric8 CRD generator.
4. Generate Java models for OCM's CRDs (`ManagedCluster`, `ManagedClusterSet`, `Placement`, `ManifestWorkReplicaSet`) with the Fabric8 `java-generator`.
5. Add `CODEOWNERS`, `CONTRIBUTING.md` and a pull request template.

**Output:** `ssp` repository with green CI on an empty project.

**Done when:** A trivial pull request runs lint and tests and merges.

## B · Platform (1 engineer)

**Task:** Script the local hub: one kind cluster running the OCM hub (with `ClusterImporter`), Cluster API and the Docker provider.

**Steps**

1. Write `hack/kind-up.sh`: one kind cluster `hub`, with the Docker socket mounted so the Cluster API Docker provider (CAPD) can create containers.
2. Install the OCM hub with `clusteradm init`; enable the `ClusterImporter` and `ManifestWorkReplicaSet` feature gates in the `ClusterManager`.
3. Install Cluster API with `clusterctl init --infrastructure docker`, with the `ClusterTopology` feature enabled.
4. Write `hack/kind-down.sh`, which also deletes CAPD's containers; document both.

**Output:** Local hub ready to create clusters.

**Done when:** Two people run the script on clean machines and get the same result.
