## A · Controllers (2 engineers)

**Task:** Status model for `KubernetesCluster`: phases, conditions, printer columns.

**Steps**

1. Define phases: `Pending`, `Provisioning`, `Registering`, `Ready`, `Deleting`, `Failed`.
2. Define conditions: `InfrastructureReady`, `ControlPlaneReady`, `WorkersReady`, `Registered`, `AddOnsHealthy`.
3. Add `@PrinterColumn` annotations for type, team, environment, version and phase.

**Output:** Status model.

**Done when:** Reviewed against the KEP's Cluster Provisioning section.

## B · Platform (1 engineer)

**Task:** Import the hand-made cluster with OCM's `ClusterImporter`; document the naming rule.

**Steps**

1. Create a `ManagedCluster` with the same name as the Cluster API cluster, which lives in a namespace of that name.
2. Watch OCM's importer read the `<name>-kubeconfig` Secret, deploy the klusterlet and accept the cluster.
3. Document the rule: `ManagedCluster` `X` imports Cluster API cluster `X/X`, or the one named in the `cluster.x-k8s.io/cluster` annotation.

**Output:** Automatic import proven.

**Done when:** The cluster is `Available` without running `clusteradm join`.
