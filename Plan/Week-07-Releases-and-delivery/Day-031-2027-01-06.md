## A · Controllers (2 engineers)

**Task:** Release controller: `Component` + `Workload` → immutable `ComponentRelease` (content-hash name, immutability webhook).

**Steps**

1. Release controller: when `Component` or `Workload` changes, build a release spec.
2. Name it by a content hash (`<component>-<hash>`).
3. Admission webhook: `ComponentRelease.spec` cannot change.

**Output:** Immutable releases.

**Done when:** Editing a release is refused; a workload change creates a new release.
