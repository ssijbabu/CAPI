**Steps**

1. Read OpenChoreo's `internal/template`: `${…}` expressions, `includeWhen`, `forEach`, custom functions, cost limits.
2. Prototype the same syntax in Java on `cel-java` (`dev.cel`); list missing extension functions.
3. Port OpenChoreo's template test cases into YAML fixtures for JUnit.
4. Render the `web-service` fixture with the prototype.

**Output:** Spike report for OQ 3.

**Done when:** The report lists gaps between `cel-java` and OpenChoreo's engine, with a recommendation.
