## B · Platform (1 engineer)

**Task:** One Flux `Kustomization` per repository, each impersonating a scoped ServiceAccount.

**Steps**

1. Create one `Kustomization` per repository on the hub.
2. Give each a ServiceAccount through `spec.serviceAccountName`.
3. Bind each ServiceAccount only to the namespaces it may write.
4. Test: a `fleet-np` change that writes to `app-checkout` fails.

**Output:** Scoped Flux writers.

**Done when:** Cross-namespace writes by Flux are refused.

## C · Experience (1 engineer)

**Task:** Backstage entity provider: `Application` → System.

**Steps**

1. Backstage entity provider: read `Application` objects from the hub.
2. Map each to a Backstage `System` with owner and links.
3. Refresh on a timer; log the count.

**Output:** Applications appear in the catalog.

**Done when:** Creating an `Application` on the hub shows a System in the catalog within the refresh interval.
